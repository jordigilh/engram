**Upstream triage (% auto-compact)**: no native support. `compaction.auto` fires only on overflow; `reserved` is an absolute token pad, not a trigger, and model-dependent (verified in `overflow.ts`: `usable = limit.input - reserved`, ignored when `limit.input` unset — issue #27706 set `reserved:800k` and still ran to ~590k). Six related feature requests all closed (`not planned`/bot); only implementation is unmerged PR #10123 (`context_threshold`). Per-model `limit` override works as a fake-% hack (7/10, maintenance tax) — parked with the branch's ongoing work.

**Shipped (append-only, never blocks)** in `opencode-plugin/`, all pure helpers unit-tested, engram-only messaging throughout (backend names never surface):
- `experimental.session.compacting` pushes methodology recall (project/family/line, MCP over CLI, preserve list) — live-verified via `POST /session/:id/summarize`, summary kept `Project: engram (family: engram, line: main)` verbatim.
- `experimental.chat.system.transform` re-applies recall on every LLM call (all interfaces; TUI-only `tui.prompt.append` deliberately not used).
- `session.compacted` observer, log-only; `tool.execute.before` engram-CLI nudge, warn-only, `engram`-token allowlist.
- Code-search probe-once (option A): read-only search detection (grep/rg/ag/ack, git grep, awk, sed -n, find, built-in grep/glob; replace ops never match) → live gateway probe (2.5s timeout, SSE-aware, tries every search/recall tool) → LLM-visible hint appended only on hits, with per-session dedupe (1×/query, 3× cap) + 10-min probe cache + pending guard. `console.error` alone never reaches the model, hence the `after`-hook append.
- Steering metric: append-only jsonl (`~/.engram/logs/opencode-nudges.jsonl`) + `metrics-report.ts` for nudge→MCP conversion. JS tests fixed (quote-aware tokenizer was truncating `'my query'`; 34/34 green) and added to CI via new `opencode-plugin-tests` job.

**Gateway fix found by the spike**: `engram_code_search`/`pattern_search` failed every call live (`'CallToolResult' object has no attribute 'is_error'`) — stdio adapter pinned mcp 2.x spelling while the venv pins mcp<2.0. Fixed via `mcp_compat.call_tool_is_error()` (same tolerant pattern as `tool_input_schema`); gateway restarted, live search returns hits, probe hits code search directly instead of the recall fallback.

**Self-testbed**: engram was already on its own gateway (docs+code backends); added `opencode.json` loading the local plugin as `project=engram` (verified `scope: local`, other repos unaffected). Dedupe gap closed live with real wiring (`dedupe-spike.ts`, kept out of `*.test.ts` since it needs `:8896`): first grep nudges, repeat silent, other session/query nudge correctly.
