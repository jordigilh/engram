# Golden fixtures

`goldens.json` is generated by `generate_goldens.py` from the **real** Python
docs flow, not from a reimplementation:

- `engram.chunking.split_markdown_sections` for keys and chunk text;
- `engram.flows.configured._document_base_id` for base IDs;
- `engram.flows.configured._retain_document` with `hindsight_retain`
  monkeypatched to capture the exact retain payload (document id, content,
  metadata, tags, timestamp);
- `engram.synthesis.synthesize_document` for key sentences, keywords, and
  stats, plus a consistency assertion against the generator's recomputation of
  the sklearn TF-IDF matrix, cosine graph, PageRank values, row sums, and
  keyword scores.

Regenerate from the repository root with the deployed flow interpreter:

```bash
PYTHONPATH=src ~/.engram/venv/bin/python \
    rust/crates/engram-ingest/fixtures/generate_goldens.py
```

The generator requires Python 3.14 because `pathlib.PurePath.suffix` differs
from 3.13 for trailing-dot names (`a.` becomes `.` on 3.14, `''` on 3.13); the
deployed flow venv is 3.14. The fixture header records the interpreter,
sklearn/networkx versions, source commit, and SHA-256 of the three Python source
files. CI does not run the generator, so review any `goldens.json` diff together
with the corresponding Python source change.
