Historical record of empirical findings from running Engram in production.

**This file is now an index.** As of 2026-08-03 the entries themselves live
in per-month files under [docs/findings/](findings/) — this kept growing
indefinitely as a single flat file (4,320 lines / 58 entries after 44 days)
with no upper bound. See the reorg entry itself,
[2026-08-03 (same day, second follow-up)](findings/2026-08.md#2026-08-03-same-day-second-follow-up-split-docsfindingsmd-into-monthly-files-considered-and-rejected-a-github-issues-migration),
for the full rationale, including why a GitHub Issues migration was
considered and rejected (short version: `engram` deliberately has no
issues-bank for itself — see
[docs/NEW_PROJECT_SETUP.md](NEW_PROJECT_SETUP.md) — and its 10 existing
GitHub issues are forward-looking feature proposals, a different, still-valid
use case that isn't changing).

Existing citations elsewhere in the codebase of the form `"see
docs/FINDINGS.md 2026-07-08"` remain resolvable: find the entry's date below,
follow the link into the right monthly file.

Recall-based historical search over these findings already works today,
independent of this file's structure — they're continuously ingested into
the live `engram-docs` Hindsight bank (see
[docs/COCOINDEX.md](COCOINDEX.md)), which is what GitHub issue
[#10](https://github.com/jordigilh/engram/issues/10)'s internal
recall-quality benchmark is built against.
