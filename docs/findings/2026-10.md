# October 2026

## 2026-10-02: Migrated the shared Hindsight bank from `cursor-memory` to `shared-memory`

The cross-project memory bank name carried an obsolete client-specific name even
though the bank is owned by Engram and shared by all configured projects. The
live Hindsight bank was migrated with the document-transfer API rather than by
re-retaining source text, preserving extracted facts, document IDs, links, and
observations without another LLM extraction pass.

Validation after import matched the source counts exactly:

| Bank | Documents | Nodes | Observations |
|------|----------:|------:|-------------:|
| `cursor-memory` (source) | 5,046 | 5,152 | 106 |
| `shared-memory` (target) | 5,046 | 5,152 | 106 |

The target bank also received the source bank's effective configuration, and
representative recalls returned the same leading content. The deployment TOML,
active flow, maintenance tools, rules, tests, launchd template, and current
documentation now use `shared-memory`. Historical findings retain
`cursor-memory` where it describes the name that was actually in use at the
time. The source bank remains available as a rollback copy while the target is
observed; the transfer archive and source snapshot are kept outside the
repository under `~/.engram/migration-export/`.
